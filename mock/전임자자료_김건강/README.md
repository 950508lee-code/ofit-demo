| 파일 | 형식 | 담긴 것 |
|---|---|---|
| 예산회계_업무메모.docx | 워드 → **PC의 한글에서 열어 '다른 이름으로 저장 > HWPX'로 저장해 `예산회계_업무메모.hwpx`를 만든다** | 매달·분기 할 일, 협의할 사람, 진행 중인 일, 주의할 점 |

| 회계팀_메일_정리.txt | 글 | 메일 세 통 요약(공사 대금 조건, 준공검사, 이월 사유) |

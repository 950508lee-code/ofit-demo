# OFIT 오핏

공공기관 업무관리체계 웹 시제품 — 2026 공공 AI 대전환 챌린지 출품용.
**일의 주인은 사람이 아니라 업무다.** 업무를 고르면 반복업무가 저절로 들어오고, 인수인계하면 기록째 넘어가고, 다른 부서 요청은 그 업무 담당자를 찾아간다.

## 실행

```
npm install
npm run dev     # http://localhost:5180
```

- 시연 순서: `docs/DEMO.md`
- 확정된 구조와 결정: `docs/STRUCTURE.md`
- **다른 AI가 이어받을 때: `AGENTS.md`부터**

모든 사람·업무·기록은 시연용 더미 자료다(`src/data/demo.ts`). 상태는 브라우저 localStorage에 저장되고, 로그인 화면의 "처음 상태로 되돌리기"로 초기화한다.

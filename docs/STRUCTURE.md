# 오핏 화면 구조 (2026-10-15 확정)

한 줄: 업무를 고르면 반복일정이 들어오고, 일정은 나·부서·그룹으로 주고받으며, 사람이 바뀌어도 업무와 일정은 그대로 이어진다.

## 전체 지도

| 자리 | 데스크톱 | 폰 | 메뉴 옆 숫자 |
|---|---|---|---|
| 홈 | 왼쪽 메뉴 1 | 아래 막대 1 | 오늘 남은 일 |
| 달력 | 왼쪽 메뉴 2 | 아래 막대 2 | 없음 |
| 그룹 | 왼쪽 메뉴 3 | 아래 막대 3 | 없음 |
| 알림 | 왼쪽 메뉴 4 | 위쪽 머리 오른쪽 '알림 n' | 안 읽은 알림 |
| 내 정보 | 왼쪽 메뉴 아래 이름 칸 | 아래 막대 4 | 없음 |

숫자는 '홈 = 오늘 남은 일'과 '알림 = 안 읽은 것' 두 곳에만 붙인다. 새로 온 것은 모두 알림으로 모은다.

## 1. 홈
- 위: 주간 한 줄 달력(이번 주 7일, 좌우로 주 넘김, 일정 있는 날 점, 오늘 강조). 날짜를 누르면 아래 목록이 그날 것으로 바뀐다.
- 받은 인수인계 요청이 있으면 목록 맨 위에 카드(날짜순 미리보기, 받기/거절).
- 고른 날 목록 순서: 기한 지난 일 → 매일 하는 일(한 줄 묶음) → 반복업무 → 받은 부서 일정(출처 표시) → 그룹 항목(그룹 이름 표시) → 내 일정.
- 맨 아래 빠른 입력. 기본 대상은 '나'. '자세히'를 누르면 일정 등록 창(대상 선택)이 열린다.
- 항목을 누르면 오른쪽(폰은 전체 화면)에 카드: 반복업무 = 언제·어떻게·지난번·완료 / 받은 일정 = 보낸 곳·내용·완료 / 그룹 항목 = 그룹·체크리스트·댓글.

## 2. 달력
- 한 달 칸 달력. 칸마다 제목 1~2개와 '외 n건'. 받은 일정·그룹 항목은 앞에 출처를 붙인다(색 대신 글자).
- 매일 하는 일은 칸마다 찍지 않고 위쪽에 '매일 하는 일 n개' 한 줄.
- 날짜를 누르면 오른쪽에 그날 목록(홈 목록과 같은 모양). 달 넘기기, 오늘로 가기.

## 3. 그룹 = 공동 프로젝트
- 목록: 내가 속한 그룹(진행 n/m, 새 소식), 그룹 만들기, 초대코드(6자리)로 참여.
- 그룹 만들기: 이름 → 초대코드 발급(다른 부서·다른 조직 사람도 코드로 참여).
- 그룹 안
  - 일정: 마감이 있는 일정 + 체크리스트 항목. 항목마다 담당자(없으면 누구나). 항목 옆에 완료한 사람·날짜. 일정마다 진행 n/m.
  - 댓글: 일정마다. 실시간 채팅은 두지 않는다(사내 메신저와 겹침, 대화가 일정에 붙어 남아야 인수인계 때 맥락이 이어짐).
  - 공지, 멤버(관리자 표시), 설정(이름 변경·탈퇴·해체).
- 내가 담당인 항목은 내 홈·달력에 기한 날짜로 들어온다. 어디서 체크해도 같은 항목이 완료된다.

## 알림 내역
- 쌓이는 것
  - 마감: 아침 '오늘 할 일' 요약, 시간 정해진 일 n분 전
  - 인수인계: 받은 요청, 내가 보낸 요청의 받음·거절
  - 부서 일정: 받은 일정(보낸 곳·기한), 내가 보낸 일정의 부서별 완료
  - 그룹: 내게 배정된 항목, 내 항목의 댓글, 공지, 초대
- 한 줄 = 종류 · 내용 · 시간('방금', '3분 전'). 안 읽은 줄은 굵게. 누르면 해당 일정·카드로 가고 읽음 처리.
- '모두 읽음', 30일 지난 알림은 자동 정리.
- 윈도우 알림(브라우저 알림)은 이 내역 중 마감 알림을 창 밖으로도 띄우는 것. 종류별 켜고 끄기는 내 정보 > 알림 설정.

## 4. 내 정보 (리마인더의 설정 자리)
- 내 업무: 맡은 단위업무 목록, 업무 추가, 단위업무 상세(반복업무 주기별, 순서 고치기).
- 인수인계: 인수인계 하기(받을 사람 → 넘길 업무 → 그 밖의 일정·그룹 항목 → 남길 말 → 날짜순 미리보기), 받은·보낸·지난 기록.
- 보낸 일정: 내가 부서로 보낸 일정과 부서별 완료 현황.
- 알림 설정(윈도우 알림 켜기, 종류별 켜고 끄기), 조직·부서, 로그아웃.

## 일정 등록 — 하나의 흐름, 대상 셋
빠른 입력이든 상세 등록이든 마지막에 '누구에게'를 고른다.
1. 나: 내 할 일에만.
2. 부서: 받을 부서(부서 트리에서 검색, 여러 곳, 즐겨찾기) + 받는 사람(전체 / ○○ 업무 담당자만) + 제목·기한·내용. 업무로 지정하면 인수인계 뒤에도 새 담당자에게 간다. 받은 사람 할 일에 출처가 붙어 바로 들어간다.
3. 그룹: 그룹 선택 + 체크리스트 항목·담당.

## 처음 화면·가입
- 첫 화면: 가입한 사람(들어가기), 가입하기, 조직 등록하기.
- 가입: 이름 → 조직 → 부서(고르기 또는 만들기, 상위 부서 지정) → 업무 고르기(직렬별로 쭉, 여러 개) → 반복일정이 줄줄이 들어감.
- 조직 등록: 조직 이름 + 업무 기준표 파일(직렬·단위업무·반복업무·주기).

## 데이터 관계
- 조직 > 부서(위아래 트리) > 사람
- 조직 > 직렬 > 단위업무 > 반복업무(기준표)
- 사람 ─ 단위업무 담당(맡은 날)
- 일정 네 종류: 반복업무 회차 · 내 일정 · 받은 부서 일정 · 그룹 항목
- 그룹(조직을 넘나듦) > 멤버 · 공지 · 일정 > 체크리스트 항목(담당·완료) · 댓글
- 인수인계 = 넘길 단위업무 + 고른 일정·그룹 항목 + 남길 말

## 넣지 않는 것
AI가 업무 카드를 만드는 기능, 실시간 채팅, 기관 목록 전수 조사, 웹 푸시(외부 푸시 서버 필요).

## 만드는 순서
1. 홈(주간 한 줄 달력 + 고른 날 목록)
2. 달력
3. 알림 내역(마감·인수인계부터, 이후 기능이 생길 때마다 종류 추가)
4. 내 정보로 내 업무·인수인계 옮기기
5. 일정 등록 대상 선택(나·그룹부터)
6. 그룹(공동 프로젝트)
7. 부서 일정 송수신(보관해 둔 부서 트리 작업 복원)

## 구현 상태 (2026-10-15)
1~7 모두 구현. 확인한 흐름: 가입(조직→부서→업무) · 홈 주간 달력 · 달력 · 알림 내역 · 내 정보 · 그룹(만들기·초대코드 참여·일정 체크리스트·댓글·공지) · 부서 일정(업무 담당자 대상 → 받음 → 완료 회신 → 보낸 쪽 현황) · 인수인계 뒤 부서 일정이 새 담당자에게 감(전임자 완료는 부서 단위로 유지).

## 화면 위계 (2026-10-15)
- **일정 등록**은 어디서나 같은 자리: 데스크톱은 메뉴 맨 위, 폰은 위 막대. 나·부서·그룹을 여기서 고른다. 빠른 입력 아래 '자세히 입력'은 쓰던 글을 들고 같은 창을 연다.
- **채운 버튼**은 메뉴의 일정 등록(항상 한자리) + 지금 일을 끝내는 것(완료·보내기·넣기·인수인계 보내기). 그룹 만들기처럼 화면 안에서 새로 여는 버튼은 테두리 버튼.
- 등록 창이 길어 아래가 잘리면 끝을 흐리고 버튼 위에 선을 긋는다.
- 인수인계 받을 사람은 부서를 함께 보이고, 같은 부서 사람이 먼저.
- 아이콘은 **폰 아래 탭에만** 둔다(KRDS 탭바: 아이콘+글자). 선 1.6px 무채색, 고른 탭은 2.1px. 코드 안에 직접 그려 외부 파일 없음. 그 밖의 화면은 글자만.
- **PC 홈**: 주인공은 고른 날(기본 오늘) 할 일. 위의 이번 주는 '흐름' 띠로만 — 날마다 점(채움=끝냄, 빈 원=남음, 지난 날 남은 것=빨강)과 "남은 n". 할 일 내용은 펼치지 않는다. 상세는 다른 화면처럼 목록 옆에 나란히.
- **줄 문장 구조**: 제목 / 자리 이름표(업무·부서·그룹, 테두리 칩, 누르면 자리 화면) / 리듬·사정(회색). 이름표 없음 = 내 일.
- **낱말**: 업무 · 반복업무 · 할 일 · 일정 등록 · 요청(부서 사이, 2026-10-16 '부서 일정'에서 바꿈: 부서에 요청 보내기·보낸 요청·받은 요청) · 그룹 항목 · 인수인계. 업무 표준 관리자는 '총괄 관리자'(외래어 '마스터' 안 씀)와 '분류 관리자'. (반복일정·넘겨주기 안 씀)
- **업무 표준 만들기(관리자 승인)**: 누구나 ① 자리 화면 '반복업무 더하기' ② 업무 고르기 아래 '업무 만들기'로 올린다. 반복업무는 한 줄 글(예: 매월 25일 지출결의 마감, 분기 첫 달 10일 …, 매월 셋째 주 수요일 …)로 쓰면 주기와 다음 날짜를 바로 보여 준다. 그 분류 관리자(Org.seriesAdmins, 없으면 마스터 Org.admins)가 내 정보 '업무 표준 검토'에서 승인하면 기준표에 들어가 같은 업무를 맡은 모두에게, 새 업무는 올린 사람 업무로. 반려는 사유와 함께 돌아간다. 관리자가 올리면 바로 반영. 자리 화면 '업무 표준'에 검토 중·승인·반려 기록.
- **시연 데이터**: src/data/demo.ts(누구나 읽는 업무 8개·반복업무 26개). 김건강(광진지사, 예산·회계·인사·복무·홍보), 최표준(본부 기획조정실, 업무 표준 관리자).
- **업무 표준 관리자**: 마스터 한 명(모든 분류 승인 + 내 정보 '분류별 관리자'에서 분류마다 관리자 지정) + 분류별 관리자(그 분류만). 올린 것은 분류 관리자에게, 없거나 새 분류면 마스터에게. 시연: 마스터 최표준, 경영지원 관리자 한경영.
- **일정 등록 창(나)**: 순서 제목 → 누구에게 → 날짜(반복이면 시작일)·시간 → 반복. 제목에 '매주 금요일 3시'처럼 쓰면 칸으로 옮긴다. 반복은 리마인더 반복 화면처럼 '매 [n] [일·주·개월·분기·년] 마다' + 세부(여러 요일 / 일자·n째 주 요일·말일 / 분기 달 / 월·일) + 공휴일·주말 건너뛰기(기본 켬). 빠른 입력과 업무 표준이 같은 해석기(takeRule)를 쓴다.
- **업무분장 관리(내 정보)**: '업무 바꾸기' = 맡은 업무가 체크된 기준표에서 넣고 빼기(리마인더 업무분장 변경). 빼거나 인수인계로 넘기면 State.until 에 '어제까지' — 그날까지 회차·완료 기록은 달력에 남고, 기한 지난 일로는 조르지 않는다. '반복 할 일' 판 = 내가 만든 것(누르면 고치기) / 업무에서 온 것(업무 표준에서 와서 여기선 못 고침, 상세에 업무 표준 안내).
- **부서·그룹 일정 반복**: 일정 등록 창에서 부서·그룹도 '반복'(첫 기한부터). 반복 묶음(State.series) 하나 + 다가오는 두 달치 회차를 보통 일정 한 건씩 만든다(앱 열 때·보낼 때 extendSeries) — 받기·완료·현황·인수인계는 한 번짜리와 같다. 받는 사람에게는 묶음으로 한 번 알림. 보낸 부서 일정·그룹 목록은 묶음마다 다가오는(안 끝난) 회차 하나. 상세에 '반복 · 매월 5일 · 이번 회차', 보낸 사람은 '반복 멈추기'(손 안 댄 앞 회차 지움).
- **시연 표시**: 시연용 계정 바꾸기를 쓰면 본문 위에 '○○ 님으로 보는 중 · 부서 · 역할' 띠.
- **자리 잡기(업무 정하기 전용 흐름, src/Settle.tsx)**: 업무는 늘 전용 화면에서 정하고 홈은 할 일만. 발령(내 정보 '부서 옮기기'): 맡던 업무 정리(같은 부서 사람에게 인수인계 또는 빼기) → 새 부서 → 받을 인수인계 → 업무 고르기 → 차오르는 장면. 업무 0개면 홈에 '자리 잡기' 버튼만(받을 인수인계 → 고르기 → 차오름). 처음 가입은 가입 흐름이 같은 부품을 쓴다.

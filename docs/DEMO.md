# 시연 순서 (PC, 약 5분)

자동 점검: `node scripts/screens/demo-flow.mjs scripts/screens/demo-flow.json` → `node scripts/screens/shoot.mjs scripts/screens/demo-flow.json <폴더>` (28단계, 단계마다 OK/CHECK, 앱 날짜 2026-10-30 고정)

| # | 장면 | 보여 줄 것 |
|---|---|---|
| 1 | 스플래시 → 시작 화면 | 시연 계정 맨 위 '박공단 · 노원지사 새 직원 · 업무분장부터'('여기서 시작') · 김건강 · 한경영 · 최표준 |
| 2 | 업무분장 고르기 → 일정 세팅 → 홈 | 업무 2개(예산·회계·인사·복무) 고르기 → "업무분장에 따라 주기업무를 일정에 넣고 있어요"(앞으로 4주 칸에 회차가 점으로 찍힘, 반복업무 8개 · 4주 할 일 n개) → 저절로 홈, 이번 주 칸과 오늘 할 일이 차례로 나타남. (이름·조직·부서부터 보이려면 '새 직원으로 시작하기') |
| 3 | 오늘 | 이번 주 할 일 칸 + 오늘 할 일(이름표·리듬) · 빠른 입력 "매주 금요일 3시 주간 회의" · 완료 → 되돌리기 |
| 4 | 업무지식 · 내 업무 | 이름표 누르기 → 업무지식: 업무 안내(그 자리에서 고치기) · 처리 순서 · 참고자료 · 업무 표준 · 지난 기록 보기 · 있었던 사람 → '내 업무에서 보기': 반복업무 · 한 해 박자 · 받은 요청 · 지난 기록 |
| 5 | 요청 | 김건강 → 노원지사 '예산·회계 담당' (받는 사람 미리보기) → 박공단 오늘 화면에 이름표·기한 선 → 한 줄 회신 완료 → 김건강 '완료한 부서 1/1' |
| 7 | 업무 표준 | 박공단 '매월 10일 예산 전용 신청 취합' 올리기 → 한경영(경영지원 관리자) 승인 → 알림 |
| 8 | 인수인계 | 김건강 → 이광진(같은 부서) 홍보 → 받기 → 업무지식 사람 선 '김건강 ~10월 · 이광진 10월~' + 전임자 기록 |
| 9 | 업무 바꾸기 | 체크된 기준표에서 넣고 빼기 |
| 10 | 달력 · 알림 | 업무 색 칩 · 오른쪽 위 알림 종(처리할 것 먼저) |

사람 바꾸기: 왼쪽 아래 "시연용 계정 바꾸기"(폰은 내 정보 맨 아래) — 로그아웃 없이 바로. 처음 상태로: 로그인 화면 "처음 상태로 되돌리기".

덧붙일 장면(선택) · 발령 첫날: 김건강 내 업무 → 부서 옮기기(발령) → 맡던 업무를 이광진에게 인수인계·홍보는 빼기 → 노원지사 → 박공단이 넘긴 계약·구매 받기 → 시설·안전 고르기 → 반복업무가 차오름 → 오늘 화면에 '받은 업무' 판. 자동 점검: `scripts/screens/move-flow.mjs`.

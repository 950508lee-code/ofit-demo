## 1. 먼저 확인한 두 가지

### 1-1. 알림 한 줄에서 종류 글자를 뺀 것 — 제목만으로 무슨 일인지 알 수 있는가

| 지금 제목(알림 한 줄에 보이는 것) | 종류 | 제목만으로 앎? | 후보 |
|---|---|---|---|
| ○○ 님이 인수인계를 보냈습니다 | 인수인계 | 예 | 유지 |
| ○○지사에서 요청이 왔습니다 · 10월 30일까지 | 요청 | 예 | 유지 |
| ○○ 업무에 반복업무가 더해졌습니다 | 업무 표준 | 예 | 유지 |
| ○○이 승인됐습니다 / 반려됐습니다 | 업무 표준 | 예 | 유지 |
| 월간 복무 점검 처리 순서 바뀜 | 처리 순서 | 예 | 유지 |
| 홍보 업무 안내 고침 | 업무 안내 | 예 | 유지 |
| **매일 하는 일 2개** · 방금 | 마감(아침 요약) | **아니오** — 남은 일인지, 끝낸 일인지, 마감인지 모름 | 제목을 "오늘 할 일 2개 남음"처럼 바꾼다 |
| **복무 점검표 양식 붙임** | 참고자료 | **아니오** — 무엇을 어디에 붙였는지 모름 | "인사·복무에 참고자료 붙음 · 복무 점검표 양식" |
| **연말정산 자료 취합 더해짐** | 업무 표준 | **아니오** — 반복업무가 더해진 것인지 모름 | "예산·회계에 반복업무 더해짐 · 연말정산 자료 취합" |

- **판단:** 종류 글자를 뺀 것 자체는 괜찮다. 다만 제목 세 개는 종류 글자가 뜻을 대신 들고 있었다.
- **후보:** 종류 글자를 되살리지 말고, 그 세 제목에 무엇(참고자료·반복업무·남음)을 넣는다. 성격이 다른 정보(처리할 것 vs 바뀐 것)는 이미 굵기로 나뉜다(처리할 것·안 읽은 것은 굵게).

### 1-2. ▶ 아이콘 — 재생인지, 다음으로 넘기기인지

- **지금:** 흐르는 중에는 ‖, 멈추면 ▶. 옆에 "1 / 3"이 있어서, ▶가 "다음 알림"으로 읽힐 수 있다(작업자 판단).
- **후보 A(추천, 아이콘):** ▶를 쓰지 않는다. ‖ 하나만 두고, 누르면 눌린 모양(바탕이 채워짐)으로 멈춤 상태를 보인다. 다시 누르면 풀린다. 아이콘이 하나라 '다음'으로 읽힐 여지가 없다.
- 후보 B: 멈춘 상태에만 글자 "다시 넘기기"를 보인다. 드문 상태라 글자 부담이 작다.

## 3. 화면을 가로지르는 문제(위계)

1. **조작 단추가 한 모양뿐이다.** 이동(업무지식·보기)·고치기(우리 부서 방식·자료 더하기)·설정(공개 범위)·지우기(떼기)가 모두 회색 밑줄 글자. → 세 갈래로 나눈다: ① 이동 = 글자 그대로, ② 고치기 = 묶음 머리 오른쪽 하나, ③ 설정·지우기 = 고치기 안이나 마우스 올렸을 때만.
2. **회색 글자가 너무 여러 무게다.** 묶음 이름·설명·출처·단추가 모두 회색 12–15px에 굵기만 조금씩 다름. → 네 층으로 고정: 제목(22 굵게) · 본문(15–16 진하게) · 보조(13 회색 보통) · 조작(14 진하게, 이동만 밑줄).
3. **설명 문장이 기능 옆에 붙어 있다.** "…에서 바꿉니다", "반복업무마다, 조직 공통", "업무 전체에 관한 것" → 삭제.
4. **빈 상태 문장.** "…이 없습니다"가 네 곳 → 묶음째 숨기거나 단추만.
5. **날짜 표기가 셋.** "10월 26일", "10월 26일 (월)", "26.09.30" → 한 가지로.
6. **같은 것을 다른 말로.** 상세 판 "어떻게" vs 업무지식 "처리 순서".
